# Website Builder Competitive Analysis — AgentSocial

## Competitors Offering Website Builder + Social Media

| Competitor | Website Feature | Type | Pricing | Notes |
|---|---|---|---|---|
| **Buffer** | Start Page | Link-in-bio / simple landing page | Free (included) | Very limited — single page, no real site builder |
| **Hootsuite** | Hootbio | Link-in-bio page builder | Included in plans ($99+/mo) | Similar to Buffer's Start Page, not a full site builder |
| **Later** | Linkin.bio | Instagram grid → landing page | Included in plans ($25+/mo) | Instagram-focused, not a general website |
| **Squarespace** | Unfold (social) + full website builder | Full site + social scheduling add-on | $16–99/mo | Closest competitor — website builder adding social, opposite direction |
| **Wix** | Full website + social post scheduler | Full site + basic social | $17–159/mo | Website-first, social is an add-on feature |
| **GoDaddy** | Website builder + social media management | Full site + social | $9.99–20.99/mo | Bundled in Marketing Suite plans |

## Key Finding
**No social media management tool offers a full website builder.** Buffer, Hootsuite, and Later only offer link-in-bio/landing page tools. The convergence is happening from the other direction — website builders (Squarespace, Wix) adding social features.

**This is a massive white space.** AgentSocial would be the first social-first platform to include a real website builder.

## Differentiation Opportunity
- **Social-first, website-second** — opposite of Squarespace/Wix
- **Agent-native** — AI agents can build and maintain sites via API
- **Integrated** — social posts drive to your site, site feeds social, all one dashboard
