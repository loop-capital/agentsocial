# Website Builder Target Personas — AgentSocial

## Primary Personas

### Persona 1: The Creator Who Hates Tech
- **Name**: CasualCreator Carla
- **Role**: Solo content creator (Instagram, TikTok)
- **Current stack**: Later/Buffer + Carrd/Linktree
- **Pain**: Managing 2+ subscriptions, site never matches social brand
- **Why AgentSocial**: One tool, one brand, one bill. Site auto-matches social aesthetic.
- **Willingness to pay**: $15–25/mo total

### Persona 2: The AI-Powered Agency
- **Name**: AgentOperator Alex
- **Role**: Runs social accounts for 5–20 clients using AI agents
- **Current stack**: Hootsuite + WordPress + custom API scripts
- **Pain**: Building client sites is slow, API integration is hacky
- **Why AgentSocial**: Agents can create/update client sites via API. White-label for agencies.
- **Willingness to pay**: $50–100/mo

### Persona 3: The Small Business Owner
- **Name**: BootstrapBiz Ben
- **Role**: Local business owner (bakery, gym, salon)
- **Current stack**: Nothing coherent — maybe a Facebook page
- **Pain**: Can't afford a web developer, doesn't know how to build a site
- **Why AgentSocial**: "I already use it for social, and now I get a website too? Done."
- **Willingness to pay**: $15–30/mo

### Persona 4: The AI Agent Itself
- **Name**: Autonomous Agent
- **Role**: Self-operating AI agent managing a human's online presence
- **Current stack**: Custom API integrations
- **Pain**: No single API to manage both social posting AND web presence
- **Why AgentSocial**: First platform with unified social + website API
- **Willingness to pay**: Determined by human owner ($15–79/mo)

## Priority Order
1. **BootstrapBiz Ben** — largest market, easiest conversion, "included" messaging
2. **CasualCreator Carla** — strong word-of-mouth, visual brand alignment
3. **AgentOperator Alex** — highest revenue per customer, API differentiation
4. **Autonomous Agent** — unique to AgentSocial, long-term strategic moat
