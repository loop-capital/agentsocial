# Oura - Health App Design Analysis

Oura is the pioneer of smart ring wearable technology, focused on sleep tracking, readiness scores, and holistic health monitoring. Valued at $11B, they've set the standard for wellness wearables.

## Key Features Highlighted

### 1. Data Visualization
- Three core scores: Sleep, Readiness, Activity
- 0-100 scoring system (intuitive and comparable)
- Trend views (daily/weekly/monthly)
- Color-coded status indicators
- Charts and graphs for biometrics

### 2. Sleep Scores
- Breakdown by: Total Sleep, Efficiency, REM, Deep, Latency, Timing
- Sleep stages visualization
- Sleep regularity tracking
- Personalized sleep insights

### 3. Readiness Scores
- Composite score based on: HRV, Body temperature, Sleep, Activity balance
- Daily recovery assessment
- Guidance on exertion levels
- Trend analysis over time

### 4. Trend Display
- Long-term health trends
- Comparison to personal baseline
- Seasonal/pattern detection
- Export capabilities for data

## UI/UX Patterns to Learn From

### ✅ Strengths
1. **Progressive disclosure**: Layers of information, animation, micro-interactions
2. **Three-score system**: Simple entry point (Sleep, Readiness, Activity)
3. **0-100 scale**: Universally understood scoring
4. **Contextual insights**: Time-aware recommendations
5. **Trend visualization**: Long-term pattern recognition
6. **Minimal friction**: Automatic data collection
7. **Today Tab**: Daily focal point with relevant highlights

### Design System Insights (from Instrument redesign)
- Inspiration from "emotional and tactical moments" of wearing the ring
- In-app UI reflected on marketing site
- Data visualization as core design language
- Lifestyle + CGI photography blend
- Accessible design (color blindness friendly)

## Key Takeaways for Basys Health

1. **Score everything**: 0-100 scales are intuitive and motivating
2. **Three core metrics**: Don't overwhelm - prioritize what matters most
3. **Trends over snapshots**: Show progress and patterns, not just current state
4. **Progressive disclosure**: Surface summary first, let users dig deeper
5. **Contextual recommendations**: Time-aware, behavior-aware insights
6. **Visual hierarchy**: Scores → Trends → Details
7. **Continuous feedback loop**: Daily engagement through daily scores
