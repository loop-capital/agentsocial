# Website Builder Feature Naming — AgentSocial

## Naming Options

### Top Recommendation: **SiteFlow**
- Implies ease + motion (content flows from social to site)
- Unique, brandable, short
- Works as both noun and verb: "Build your SiteFlow"

### Strong Alternatives

| Name | Vibe | Pros | Cons |
|---|---|---|---|
| **WebPulse** | Dynamic, living | Implies site is alive/active | Slightly generic |
| **SocialSite** | Literal | Immediately clear | Too descriptive, not brandable |
| **Presence** | Premium | Covers social + web presence | Already used by other products |
| **LinkBase** | Utility | Connects to link-in-bio concept | Sounds like a database tool |
| **AgentSite** | Agent-native | Ties to AgentSocial brand | Limits perceived audience to agents only |
| **OnePage** | Simple | Sets expectation | Implies limitation |
| **Homebase** | Central, commanding | Feels like a hub | Used by HR software |

### Recommendation
1. **Primary**: SiteFlow — brandable, implies integration with social flow
2. **Subtitle/tagline**: "Your social presence, with a home base"
3. **Internal codename**: Project SiteFlow

## Messaging Framework
- **Before**: "Manage your social media"  
- **After**: "Manage your social media AND your website — one platform, one login"
- **Key differentiator phrase**: "Social-first website builder"
