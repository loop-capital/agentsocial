About

AgentSocial is a social media management platform built agent-first. It enables users to generate, schedule, and distribute content efficiently across multiple platforms including TikTok, Instagram, YouTube, Facebook, Twitter/X, and LinkedIn. The platform provides an open API, native agent integrations, and a memory engine that tracks engagement to improve content over time.

Features

Open API: Full REST API + Webhooks. Your key, your data.

Multi-Platform: Connect and post to TikTok, Instagram, YouTube, Facebook, Twitter/X, and LinkedIn from one dashboard.

Content Scheduling: Plan and schedule posts across all platforms with optimal timing recommendations.

Analytics: Track performance metrics and engagement across all connected accounts.

TikTok Integration

AgentSocial integrates with TikTok to allow users to:

  • Connect their TikTok account via OAuth
  • Schedule and publish TikTok videos
  • Upload video content directly to TikTok
  • Track video performance metrics (views, likes, shares)
  • Repurpose content from other platforms to TikTok format
