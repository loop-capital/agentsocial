# AgentSocial Cloud Infrastructure

Provisioning scripts for deploying AgentSocial + Dograh voice agent on Hetzner Cloud VPS.

## Quick Start

### 1. Prerequisites

- Hetzner Cloud account + API token
- SSH key registered in Hetzner Cloud (named `agentsocial`)
- Ansible installed locally (`pip install ansible`)
- Docker Compose v2 on the target VPS (installed by Ansible)

### 2. Provision a New Client

```bash
# Set your Hetzner token
export HETZNER_TOKEN=your_hetzner_api_token

# Provision (creates VPS, installs stack, configures SSL)
./scripts/provision.sh pleij pleij.clawstudio.co $HETZNER_TOKEN
```

This takes ~15-20 minutes and outputs:
- VPS IP address
- All service URLs
- Generated credentials in `infra/.env.pleij`

### 3. Check Status

```bash
# List all instances
./scripts/status.sh

# Check specific client
./scripts/status.sh pleij
```

### 4. Destroy a Client

```bash
# ⚠️ Permanently deletes VPS and all data
./scripts/destroy.sh pleij $HETZNER_TOKEN
```

## Architecture

```
Internet → Caddy (443/80) → ┌─ AgentSocial Web (:3000)
                               ├─ AgentSocial API (:3001)
                               ├─ Dograh UI (:3020)
                               └─ Dograh API (:8010)
                                      │
                               ┌──────┤
                               │      │
                          PostgreSQL  Redis  MinIO
```

## Client Configuration

Each client needs a `.env.<client_name>` file with:

1. **Client identity**: `CLIENT_DOMAIN`, `CLIENT_NAME`
2. **Database passwords**: Auto-generated by provision script
3. **API keys**: OpenAI, Deepgram, ElevenLabs, Twilio, Square, Composio
4. **Adobe Client ID**: For Express SDK integration

## Voice Agent Setup (Post-Provision)

1. Navigate to `https://<client_domain>/voice`
2. Create an organization and workflow
3. Configure Twilio webhook: `https://<client_domain>/voice-api/api/v1/voice/webhook/twilio`
4. Set up Deepgram, OpenAI, and ElevenLabs API keys in Dograh settings
5. Test with a phone call

## Monitoring

- **Health checks**: Every 5 minutes via cron
- **Backups**: Daily at 3 AM ET (PostgreSQL dumps, 7-day retention)
- **Watchtower**: Auto-updates Docker images every 12 hours
- **Fail2ban**: SSH brute-force protection
