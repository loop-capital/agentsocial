## How Zoca's Client Funnel Works

```
USER SEARCHES: "hair salon near me"
         ↓
Google shows Local Pack (organic ranking)
         ↓
User clicks Pleij Salon's GBP profile
         ↓
GBP profile shows "Website" button
         ↓
Click → pleijsaloncolumbus.zoca.com
         ↓
Landing page loads with services + form
         ↓
User submits form or uses AI chat
         ↓
Lead captured in Zoca system
         ↓
Salon notified via dashboard/SMS
         ↓
Booking confirmed in Fresha/Vagaro/Square
```

**No paid ads in this funnel. All organic.**
