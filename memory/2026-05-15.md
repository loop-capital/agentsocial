### Architecture
```
Customer calls PLEIJ Salon
         ↓ Twilio
    Dograh Voice Agent (localhost:8010)
    ├── STT: Deepgram (speech-to-text)
    ├── LLM: GPT-4o-mini (conversation)
    ├── TTS: ElevenLabs (text-to-speech)
    └── Workflow: Greet → Qualify → Book → Transfer
         ↓ Webhooks
    AgentSocial API (localhost:3001)
    ├── Lead capture
    ├── Booking sync
    ├── Analytics
    └── Campaign triggers (rebooking, reviews)
```

### Cost Analysis (Self-Hosted vs Vapi)
| For PLEIJ Salon (~500 calls/mo) | Self-Hosted | Vapi |
|---|---|---|
| Platform | $0 | $0.05/min = $25/mo |
| STT (Deepgram) | ~$3 | Included |
| LLM (GPT-4o-mini) | ~$2 | Included |
| TTS (ElevenLabs) | ~$3 | Included |
| Twilio | ~$7 | ~$7 |
| **Total** | **~$15/mo** | **~$32/mo** |

For 100 salons (DFY scale): **$1,500/mo** vs **$3,200/mo** — we save $1,700/mo
