**Solution Applied via Supabase SQL Editor**:
```sql
-- Grant schema USAGE (the critical fix)
GRANT USAGE ON SCHEMA public TO service_role;

-- Grant table permissions
GRANT ALL ON ALL TABLES IN SCHEMA public TO service_role;
GRANT ALL ON ALL SEQUENCES IN SCHEMA public TO service_role;
```

**Diagnostic Query Used**:
```sql
SELECT nspname, 
       pg_catalog.has_schema_privilege('anon', nspname, 'USAGE') as anon_can_use,
       pg_catalog.has_schema_privilege('authenticated', nspname, 'USAGE') as auth_can_use,
       pg_catalog.has_schema_privilege('service_role', nspname, 'USAGE') as service_can_use
FROM pg_catalog.pg_namespace 
WHERE nspname = 'public';
```
Result before fix: `service_role` showed `false` for USAGE.

## CLI-Anything Reference (Saved for Future Use)

**Source:** https://github.com/HKUDS/CLI-Anything
**Date Saved:** 2026-04-12

### What It Is
CLI-Anything is a framework for making CLI tools "agent-native" - allowing AI agents to use software tools programmatically without human intervention.

### Key Features
- Wraps existing CLI tools with structured interfaces
- Community hub (cli-hub) for sharing CLI wrappers: `pip install cli-anything-hub`
- Allows agents to discover and use commands automatically
- Bridges AI agents with the world's software

### When to Use
- When needing structured interfaces to specific CLI tools (e.g., "use Figma's CLI to export frames")
- When OpenClaw's native `exec` or toolset doesn't cover a specific CLI need
- For integrating complex software that requires structured command sequences

### Installation
```bash
pip install cli-anything-hub
cli-hub install <name>
```

### Comparison with OpenClaw
| OpenClaw | CLI-Anything |
|----------|--------------|
| Built-in `exec` for any CLI | Structured wrappers for specific tools |
| Browser, web, file tools | CLI-specific integrations |
| Skills ecosystem | CLI-Hub community wrappers |

**Note:** OpenClaw already provides extensive tool coverage. CLI-Anything adds value for specialized CLI tool integrations that need structured agent interfaces.
