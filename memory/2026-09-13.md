## What was built

### API (`packages/api`)
- Added `generateText` method to `GenerationService` (`src/services/generation.ts`) using muapi `gemini-2.0-flash`.
- Created Cloudinary helper (`src/services/cloudinary.ts`) with optional fallback when env vars are missing.
- Created new route module `src/routes/generate-post-assets.ts`:

  - `POST /generate/video-from-caption` — generates video via muapi `seedance-2.0`, returns `jobId`.
  - `GET /generate/video-from-caption/:jobId` — polls status, returns `videoUrl` on completion.
  - `POST /generate/related-posts` — fetches a post, generates platform-tailored captions + hashtags via AI.
