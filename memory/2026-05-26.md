## Client Onboarding: AI Receptionist Setup Process

Jason asked: "What is the setup process for the AI receptionist for our clients?"

### Two Integration Paths

**Path A: Integrated Booking** (client uses supported provider)
- Determine provider (Square, Phorest, Booker, etc.)
- Client authorizes API access
- Voice agent pulls real-time availability + books directly
- SMS confirmation with booking link

**Path B: Lead Capture** (no booking integration OR client prefers manual)
- Voice agent collects: name, phone, preferred service, preferred stylist, preferred date/time
- Sends lead via SMS/email to salon staff
- Staff calls back to confirm and manually books
- Many small salons will start on Path B — they just want someone to answer the phone

### Important Design Decision
- **Square will NOT be the only service provider**
- Must determine which provider each client uses
- Some salons may prefer lead capture over direct booking
- System must be provider-agnostic at the onboarding layer

### Onboarding Flow (v2)
1. **Discovery** (5 min) — What scheduling system? Direct book or lead capture?
2. **Provider Connection** (Path A only, 5 min) — Authorize API
3. **Business Profile** (10 min) — Name, address, hours, staff, services, lead delivery prefs
4. **Voice & Branding** (5 min) — Receptionist name, TTS voice, greeting, SMS on/off
5. **Phone Setup** (5 min) — Provision Twilio number, forward existing line
6. **Test & Go Live** (15 min) — Test calls, approve pronunciations, verify booking flow

Total: ~30-40 minutes per client

## Booking Provider API Research

Jason requested research on: Vagaro, Meevo (Millennium), Boulevard, Booker (Mindbody), Phorest
Also researched: Fresha, Schedulicity

### Results

| Provider | Verdict | API? | Market | Integration Path |
|----------|---------|------|--------|-----------------|
| **Square** | 🟢 Done | Full REST | US salons | Already integrated |
| **Phorest** | 🟢 Green | Full REST, self-serve signup | UK/EU, growing US | Best next target — live availability, booking, clients |
| **Booker/Mindbody** | 🟡 Yellow | Full API but gated behind approval | Huge US market share | Apply for API access, ~1-2 week approval |
| **Boulevard** | 🟡 Yellow | Has API, dev portal behind auth | Modern salons, mid-luxury | Need partnership outreach |
| **Vagaro** | 🔴 Red | No public API docs | 50K-100K salons | Highest-ROI target if we unlock via BD |
| **Meevo/Millennium** | 🔴 Red | API link 404s | Enterprise salons | Direct partnership required |
| **Fresha** | 🔴 Red | No API at all | 100K+ businesses | Marketplace model — no incentive to open |
| **Schedulicity** | 🔴 Red | No API | Small, not salon-specific | Low priority |

### Recommended Integration Order
1. **Phorest** — Self-serve API, full booking + availability, easy win
2. **Booker** — Apply for access now (1-2 week lead time)
3. **Vagaro + Boulevard** — BD outreach conversations
4. **Meevo, Fresha, Schedulicity** — Lead capture mode for now

### Lead Capture Fallback
For 🔴 Red providers (no API), AI receptionist takes caller info and routes to salon via SMS/email. No booking software needed on client's end.
