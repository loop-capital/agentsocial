## Features Section

### Feature 1: Agent-First API
**An API that actually works. Always.**

- RESTful + WebSocket. No rate-limit surprises.
- Full CRUD on posts, schedules, analytics, and media.
- Webhooks for every event — published, failed, engaged, scheduled.
- No "apply for access" forms. No waiting. Your key, your data.

*Buffer's API has been "coming soon" for years. Ours shipped on day one.*

### Feature 2: Native Agent Integration
**OpenClaw skill included. LangChain tools available.**

- One command to connect: `agentsocial connect`
- Post from any agent framework — OpenClaw, LangChain, AutoGPT, CrewAI
- Built-in skill for OpenClaw with schedule, publish, and analyze actions
- Your agent doesn't need a browser. It needs a token.

### Feature 3: Memory-Driven Optimization
**Your agent gets smarter every time it posts.**

- Tracks engagement patterns per brand, per channel, per content type
- Feeds performance data back into your agent's context
- Auto-suggests optimal posting times, formats, and hashtags
- The more your agent uses it, the better it gets — without you lifting a finger

*Humans guess. Agents learn.*

### Feature 4: Multi-Agent Workflows
**One agent writes. Another reviews. A third publishes.**

- Content creation agent drafts posts
- Approval agent reviews against brand guidelines
- Publishing agent schedules and posts at optimal times
- Role-based permissions keep the chain tight
- Built-in approval gates so nothing goes live without sign-off

### Feature 5: Per-Brand Pricing
**Stop paying per channel. Pay per brand.**

- Buffer charges you for every social account. 5 channels? 5x the price.
- AgentSocial charges per brand. Connect every channel under one brand for one price.
- 3 brands, 15 channels, one simple number on your invoice.

## FAQ

**Wait, this is for AI agents? Not humans?**
It's for both. Humans set the strategy. Agents do the work. The API is designed for agents first, but the dashboard works great for humans too.

**What social platforms do you support?**
Twitter/X, LinkedIn, Instagram, Facebook, Threads, Pinterest, and Bluesquare on day one. More coming.

**How is this different from Buffer?**
Buffer's API is closed. Their pricing is per-channel. They were built for humans clicking buttons. We were built for agents making API calls. Different product, different philosophy.

**Do I need an AI agent to use this?**
No. The dashboard is fully functional for human use. But if you have an agent, you'll wonder how you ever managed social without one.

**What's the OpenClaw skill?**
A plug-and-play skill that lets any OpenClaw agent schedule, publish, and analyze social media with natural language commands. `agentsocial post "Hello world" to twitter` — that's it.

**Is there a free tier?**
Yes. 1 brand, 3 channels, 50 posts per month. No credit card required. Perfect for testing your agent workflow.

**Can I cancel anytime?**
Yes. No contracts, no lock-in. Your data is yours. Export it anytime.
