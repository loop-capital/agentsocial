# Gateway Memory Fix - 2026-04-29

## Problem
Agents dying at ~13 minutes due to OOM killer. systemd service has MemoryMax=4G.

## Root Cause
- Gateway RSS ~1.26GB but agent sessions + child processes hit 4GB cgroup limit
- WSL has ~8GB total RAM, only 4GB allocated to openclaw service
- Current MemoryAvailable: 174MB (critically low)

## Applied Fixes

### 1. Compaction Config (applied, needs restart)
In `/home/jason/.openclaw/openclaw.json`:
```json
{
  "agents": {
    "defaults": {
      "compaction": {
        "mode": "safeguard",
        "reserveTokens": 8000,
        "keepRecentTokens": 4000,
        "maxHistoryShare": 0.5,
        "recentTurnsPreserve": 2,
        "truncateAfterCompaction": true,
        "maxActiveTranscriptBytes": "10mb"
      }
    }
  }
}
```

### 2. Systemd Memory Limit (PENDING - requires manual edit)
File: `/home/jason/.config/systemd/user/openclaw-gateway.service`

Change:
```ini
[Service]
MemoryMax=6G
MemoryHigh=5G
```

From current:
```ini
[Service]
MemoryMax=4G
MemoryHigh=3G
```

### 3. WSL Config (optional, requires wsl --shutdown)
File: `/mnt/c/Users/$USER/.wslconfig`
```ini
[wsl2]
memory=12GB
processors=6
swap=8GB
```

## Commands to Apply

```bash

nano ~/.config/systemd/user/openclaw-gateway.service
# Change MemoryMax=4G to MemoryMax=6G
# Change MemoryHigh=3G to MemoryHigh=5G

# Verify
```
