# DFY + GetUpLook Integration Strategy — 2026-05-12

## Core Insight
The DFY features (GBP, reviews, chat widget, booking, ads, campaigns) serve DUAL purposes:
1. **Paid feature for professionals** — They pay $199-499/mo for DFY services
2. **GetUpLook traffic engine** — Every professional we manage drives traffic to GetUpLook.com

## How It Works

### For Each Professional We Onboard:
- Their GBP listing → links back to GetUpLook.com profile page
- Their chat widget → powered by GetUpLook (branded footer)
- Their reviews → aggregated on GetUpLook (with permission)
- Their booking CTA → routes through GetUpLook booking system
- Their ads → managed by us, landing pages on GetUpLook subdomain

### Flywheel Effect
```
More Professionals → More GBP Listings → More Local SEO → More GetUpLook Traffic
More Traffic → More Professionals Want In → More Revenue → More Features
```

## Pricing Model
| Tier | Price | What They Get | What GetUpLook Gets |
|------|-------|---------------|---------------------|
| Core | $49/mo | Social scheduler + AI content | Profile on GetUpLook |
| Pro | $199/mo | + GBP, reviews, chat, rebooking | Enhanced profile + traffic |
| Elite | $499/mo | + Full DFY, $500 ad spend, account manager | Featured listing + backlinks |

## Traffic Generation Mechanics
1. **GBP Optimization** — Every client's GBP links to their GetUpLook profile
2. **Review Aggregation** — Reviews feed into GetUpLook category pages
3. **Chat Widget Footers** — "Powered by GetUpLook" on every widget
4. **Booking Flow** — Confirmation emails from getuplook.com domain
5. **Ad Landing Pages** — Hosted on GetUpLook subdomains
6. **SEO Network Effect** — Interlinked professional profiles = domain authority
