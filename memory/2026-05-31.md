
## Generation Service: Character & Voice Profile Endpoints (23:50 EDT)

Added Gemini Omni Character and Voice Profile support:

### New Endpoints
- `POST /api/v1/generate/character` — Create reusable character (FREE)
  - Input: reference photo URL + description → returns character_id
  - character_id persists and can be used in unlimited future videos
  - Optional: attach voice profile IDs
- `POST /api/v1/generate/voice-profile` — Create voice profile (FREE)
  - Input: preset voice base + description → returns audio_id
  - audio_id reusable across characters and videos
- `POST /api/v1/generate/character-video` — Generate video with characters
  - Pass character_ids + optional audio_ids for consistent talking-head content
  - Default model: gemini-omni-text-to-video ($1.50) or gemini-omni-image-to-video ($1.50)

### Key Insight: Omni Character Workflow
1. Create character once (FREE) from a reference photo — full body, not just face
2. Create voice profile once (FREE) — clone from reference or build from preset
3. Generate unlimited videos referencing the character_id — $1.50/video
4. Character + voice consistency maintained across all generations

### vs HeyGen
- muapi Omni: $0 setup + $1.50/video, no subscription, character+voice FREE
- HeyGen: $29/mo minimum + 20 credits/min for Avatar IV
- For 10 videos/month: muapi = $15 vs HeyGen = $29+

### Use Cases (All Business Verticals)
- Salon stylists → service demos, before/after walkthroughs
- Real estate agents → property tours, neighborhood guides
- Fitness coaches → workout demos, form corrections
- Restaurant chefs → menu highlights, cooking content
- Any brand → consistent full-body spokesperson across all content
- NOT limited to talking heads — full-body characters

### Salon/Client Use Case
- Create a character per brand representative (1 ref photo → character_id)
- Create a brand voice profile (tone, style → audio_id)
- Generate consistent full-body content: character + voice in every video
- Works across ALL verticals: salons, real estate, fitness, restaurants, any brand

## Plausible Analytics Decision (00:08 EDT)

**Decision**: Self-host Plausible on Hetzner as infrastructure, not an upsell product.

### Why
- Open source, free to self-host
- Privacy-first (no cookie banners for client sites)
- Stats API feeds into our existing analytics dashboard
- Clients see simple metrics inside AgentSocial, not a separate tool

### What We Charge
- Nothing extra. Built into every plan.
- Core ($49-79/mo): "Site analytics included"
- The value isn't the analytics tool — it's the insights and recommendations we derive from it

### Integration Plan
1. Self-host Plausible on Hetzner alongside the platform ($0/mo)
2. Add Plausible tracking script to every SiteFlow site we build
3. Pull stats via API into AgentSocial analytics page (3 numbers: visitors, top pages, conversion rate)
4. Feed data into content recommendations and AISO audits
5. Track booking button clicks as conversion goals

### NOT Building
- No separate Plausible dashboard for clients
- No analytics upsell tier
- We own the data pipeline, clients see results in our UI
