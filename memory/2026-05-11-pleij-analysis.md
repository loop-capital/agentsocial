- **Hero**: Salon name + "Best Salon in Columbus" (SEO keyword)
- **Services grid**: 14 service categories with "View Service" buttons

  - Hair Color
  - Bridal Services
  - Permanent Makeup

  - Men's Grooming
  - Hair Restoration
  - Consultations
  - Hair Treatments
  - Kid's Styling
  - Add-Ons
  - Lash & Brow Shaping
  - Facial Services
  - Makeup Services
- Each service has a short description + button

### 2. Service Detail Pages
- Individual pages per service category
- "View Service" button (likely links to booking)

### 3. Booking Integration
- UTM tracking: `?utm_source=googlemaps&utm_medium=googlemaps&utm_campaign=googlemaps`
- This confirms they run Google Local Ads → landing page → booking

### 4. Mobile-First Design
- Simple, clean layout
- Large tap targets
- Fast loading (critical for ads)
