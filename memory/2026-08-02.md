## Generation API Expansion — 4 New Endpoints + 2 Updated

Built and deployed full voice cloning, lipsync, TTS, and multi-reference pipeline for PLEIJ digital twin workflow.

### New Endpoints
| Endpoint | Method | What it does |
|----------|--------|-------------|
| `/generate/voice-clone` | POST | Clone voice from audio sample (minimax-voice-clone $0.65 or suno-voice-clone FREE) |
| `/generate/upload-audio` | POST | Upload WAV/MP3/M4A → hosted audioUrl + audioId |
| `/generate/lipsync` | POST | Face image + audio → talking head video (13 models) |
| `/generate/seedance-multi-ref` | POST | Up to 5 images + video + audio → guided video (Seedance 2.5) |
| `/generate/tts` | POST | Text → speech with optional voice_id (6 TTS models) |

### Updated Endpoints
| Endpoint | Change |
|----------|--------|

| `/generate/character-video` | Now accepts `imageUrls[]` (up to 5) + `audioUrl` for lipsync models |

### PLEIJ Digital Twin Workflow (all on muapi)
1. Upload Tiche's voice → `POST /generate/voice-clone` → `voice_id`
2. Generate new speech → `POST /generate/tts` with `voice_id`
3. Upload Tiche's photos → `POST /generate/character` (up to 5 images)
4. Face + audio → `POST /generate/lipsync` → talking head at $0.20–$0.75/video
5. Or: multi-photo reference → `POST /generate/seedance-multi-ref` → $1.50–$3.60/video
